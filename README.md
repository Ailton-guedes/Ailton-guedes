### 🚀 Projeto em Destaque

**AulaConnect — Sistema de Gerenciamento de Aulas**

Aplicação Full Stack em desenvolvimento, voltada à organização de aulas, alunos, responsáveis, agendamentos e pagamentos para professores autônomos.

**Tecnologias:** Python, FastAPI, React, JavaScript, MySQL e SQLAlchemy.

**Funcionalidades desenvolvidas:**
- Cadastro e gerenciamento de usuários.
- Autenticação de usuários com JWT.
- Cadastro e gerenciamento de alunos e responsáveis.
- Desenvolvimento de APIs para aulas, agendamentos e pagamentos.
- Estruturação de funcionalidades para acompanhamento da evolução dos alunos e notificações.
- Desenvolvimento de painel administrativo e interface de cadastro de alunos.

**Status:** Em desenvolvimento, com integração entre front-end e back-end ainda em andamento.
